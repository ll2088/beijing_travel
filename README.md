# beijing_travel

北京4天3晚旅游计划（自由行骨架，按区域顺路安排，减少往返）。

## 行前准备与预约规则

- 故宫：须提前在官方渠道实名预约，通常提前7天放票，周一闭馆（法定节假日除外），出行前以官方公告为准。
- 天安门广场：须实名预约，按预约时段入场。
- 中国国家博物馆：须实名预约，周一闭馆，热门时段放票后尽快预约。
- 长城：八达岭或慕田峪二选一，建议提前购买门票及缆车/滑车票。
- 颐和园、天坛公园：建议提前在线购票，旺季限流时现场可能无法购票。
- 官方预约入口参考：[故宫博物院](https://www.dpm.org.cn/)、[天安门广场预约](https://yuyue.tamgw.beijing.gov.cn/)、[中国国家博物馆](https://www.chnmuseum.cn/)、[颐和园](https://www.summerpalace-china.com/)、[天坛公园](https://www.tiantanpark.com/)。

## 第一天：中轴线经典线

- 上午：天安门广场（按预约时段入场）→ 故宫博物院（中轴线+珍宝馆，约3–4小时）。
- 下午：景山公园登万春亭俯瞰故宫全景。
- 晚上：前门大栅栏一带用餐，品尝北京小吃。
- 交通：地铁1号线天安门东/西站，景点间以步行为主。

## 第二天：长城一日

- 上午：前往八达岭长城（或慕田峪长城），建议早出发避开人流。
- 下午：返程后可顺路游览奥林匹克公园（鸟巢、水立方外观）。
- 交通：八达岭可乘市郊铁路S2线或旅游专线；慕田峪可乘专线巴士。
- 提示：长城段选择需结合体力与缆车/滑车安排，提前购票。

## 第三天：皇家园林线

- 上午：颐和园（东宫门进，昆明湖、长廊、佛香阁）。
- 下午：圆明园遗址公园（与颐和园相邻，顺路游览）。
- 晚上：中关村或五道口用餐。
- 交通：地铁4号线北宫门站/圆明园站。

## 第四天：天坛与什刹海

- 上午：天坛公园（祈年殿、回音壁）。
- 下午：什刹海、南锣鼓巷一带逛老胡同，可参观恭王府（需预约）。
- 晚上：根据返程时间安排送站。
- 交通：地铁5号线天坛东门站，8号线什刹海站。

## 预算参考

- 淡季（11月–次年3月）：人均约2000–3000元（经济型酒店+公共交通+常规门票）。
- 旺季（4月–10月及法定节假日）：人均约3000–4500元，酒店与交通价格上浮明显。
- 门票参考：故宫旺季60元/淡季40元，颐和园旺季30元/淡季20元，天坛联票旺季34元/淡季28元，八达岭长城旺季40元/淡季35元。
- 跟团/私家团报价随人数、酒店档次和节假日浮动，仅作对比参考，须以官方渠道核实。

## 风险提示

- 闭馆风险：故宫、国家博物馆等周一闭馆，行程需避开。
- 限流风险：热门场馆旺季限流，预约失败时启用备用景点（如北海公园、景山公园、首都博物馆）。
- 天气风险：冬季寒冷、夏季高温多雨，长城与户外行程需关注天气预报并备好衣物。
- 预约规则与开放时间可能调整，出行前务必查询官方最新公告。
- 部分攻略为个人经验，交通耗时和排队情况随季节变化，建议预留弹性时间。
