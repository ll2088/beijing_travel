# beijing_travel

北京4天3晚旅游计划（自由行骨架，按区域顺路安排，减少往返）。

## 行程总览与四片区骨架

本行程按“同区顺路、不折返”原则划分为四个片区，每天集中在一个片区活动，减少跨区通勤：

| 天数 | 片区 | 核心景点 | 住宿建议 |
| --- | --- | --- | --- |
| 第1天 | 中轴线片区 | 天安门广场、故宫、景山、前门大栅栏 | 崇文门/前门（地铁2号线、8号线） |
| 第2天 | 京北长城片区 | 八达岭或慕田峪长城、奥林匹克公园 | 同上，早出发 |
| 第3天 | 海淀园林片区 | 颐和园、圆明园、中关村/五道口 | 西直门（地铁2/4号线） |
| 第4天 | 东城人文片区 | 天坛、什刹海、南锣鼓巷、恭王府 | 按返程车站选择 |

不折返理由：第1天中轴线景点集中在天安门—故宫—景山—前门一线，步行或短途地铁即可串联；第2天长城在城区西北方向，返程顺路经奥林匹克公园；第3天颐和园与圆明园同属海淀、地铁4号线相邻两站；第4天天坛与什刹海同属东城，地铁5号线转8号线可达。

## 出发前准备与预约清单

出发前建议完成以下事项，所有预约规则与价格均须以官方渠道当日公告为准：

- 故宫博物院：须提前在官方渠道实名预约，通常提前7天放票，周一闭馆（法定节假日除外）。官方入口：[故宫博物院](https://www.dpm.org.cn/)。
- 天安门广场：须实名预约，按预约时段入场。官方入口：[天安门广场预约](https://yuyue.tamgw.beijing.gov.cn/)。
- 中国国家博物馆：须实名预约，周一闭馆，热门时段放票后尽快预约。官方入口：[中国国家博物馆](https://www.chnmuseum.cn/)。
- 颐和园：建议提前在线购票，旺季限流时现场可能无法购票。官方入口：[颐和园](https://www.summerpalace-china.com/)。
- 天坛公园：建议提前在线购票。官方入口：[天坛公园](https://www.tiantanpark.com/)。
- 长城：八达岭或慕田峪二选一，建议提前购买门票及缆车/滑车票。
- 恭王府：需预约，具体规则以官方公告为准。
- 证件与交通：携带身份证，提前下载北京地铁App或开通乘车码；往返车票/机票建议提前预订。
- 住宿：优先选择地铁2/4号线沿线（崇文门、西直门、宣武门），便于覆盖四个片区并预留往返车站机场的缓冲时间。

## 第1天：中轴线片区（天安门—故宫—景山—前门）

- 上午：天安门广场（按预约时段入场，约1小时）→ 故宫博物院（中轴线+珍宝馆，约3–4小时）。
- 下午：景山公园登万春亭俯瞰故宫全景（约1小时）。
- 晚上：前门大栅栏一带用餐，品尝北京小吃。
- 交通：地铁1号线天安门东/西站，景点间以步行为主。
- 不折返说明：天安门、故宫、景山、前门自北向南一线排列，步行即可串联，无需回头。
- 备选方案：若故宫预约失败，可改去国家博物馆（需预约）或北海公园；若体力不足，下午可省略景山，直接到前门休息。

## 第2天：京北长城片区（长城—奥林匹克公园）

- 上午：前往八达岭长城（或慕田峪长城），建议早出发避开人流，游览约3–4小时。
- 下午：返程后顺路游览奥林匹克公园（鸟巢、水立方外观，约1小时）。
- 晚上：返回市区用餐，早点休息。
- 交通：八达岭可乘市郊铁路S2线或旅游专线；慕田峪可乘专线巴士。
- 不折返说明：长城位于城区西北方向，返程进城途中顺路停靠奥林匹克公园，避免单独再跑一趟。
- 备选方案：若天气不佳或体力有限，可改乘缆车/索道上下；家庭出游可选慕田峪索道上下，减少步行。

## 第3天：海淀园林片区（颐和园—圆明园）

- 上午：颐和园（东宫门进，昆明湖、长廊、佛香阁，约3小时）。
- 下午：圆明园遗址公园（与颐和园相邻，顺路游览，约2小时）。
- 晚上：中关村或五道口用餐。
- 交通：地铁4号线北宫门站/圆明园站。
- 不折返说明：颐和园与圆明园同属海淀、地铁4号线相邻两站，按北宫门进、圆明园出的顺序游览不走回头路。
- 备选方案：体力一般者可乘颐和园游船替代部分步行；若时间紧张，可只选颐和园，圆明园改为次日或省略。

## 第4天：东城人文片区（天坛—什刹海—南锣鼓巷）

- 上午：天坛公园（祈年殿、回音壁，约2–3小时）。
- 下午：什刹海、南锣鼓巷一带逛老胡同，可参观恭王府（需预约）。
- 晚上：根据返程时间安排送站。
- 交通：地铁5号线天坛东门站，8号线什刹海站。
- 不折返说明：天坛与什刹海同属东城，地铁5号线转8号线可达，下午沿什刹海—南锣鼓巷一线步行游览。
- 备选方案：若返程时间较早，可只游天坛；若恭王府预约失败，可改逛烟袋斜街或北海公园。

## 预算参考

以下为估算区间，实际以预订时价格为准：

- 淡季（11月–次年3月）：人均约2000–3000元（经济型酒店+公共交通+常规门票）。
- 旺季（4月–10月及法定节假日）：人均约3000–4500元，酒店与交通价格上浮明显。
- 门票参考：故宫旺季60元/淡季40元，颐和园旺季30元/淡季20元，天坛联票旺季34元/淡季28元，八达岭长城旺季40元/淡季35元。
- 跟团/私家团报价随人数、酒店档次和节假日浮动，仅作对比参考，须以官方渠道核实。

## 风险提示与应急

- 闭馆风险：故宫、国家博物馆等周一闭馆，行程需避开；出发前再次确认各馆开放日。
- 限流风险：热门场馆旺季限流，预约失败时启用备用景点（如北海公园、景山公园、首都博物馆）。
- 天气风险：冬季寒冷、夏季高温多雨，长城与户外行程需关注天气预报并备好衣物；遇极端天气及时调整户外安排。
- 交通风险：早晚高峰地铁拥挤，预留弹性时间；长城一日游选择正规交通，警惕低价团和景区野导的隐形消费。
- 应急提示：保存住宿地与就近医院信息，随身携带身份证和常用药品；预约规则与开放时间可能调整，出行前务必查询官方最新公告。
- 来源说明：本行程骨架参考公开旅游攻略（检索日期2025年，来源为自媒体与旅行社内容），价格与预约规则未经官方逐项核实，请以官方发布为准。
