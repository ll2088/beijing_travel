# 北京4天3晚行程（Day1–Day4）

> 来源：综合 Trip.com 北京4天3晚京味攻略、家庭悠闲版方案、北京深度旅游全攻略、不赶路不走回头路行程等公开攻略（检索日期：2025-06-01），并结合当前仓库 README 既有骨架整理。门票价格与开放时间以官方渠道为准。

## 总体安排

- 节奏：经典打卡为主，按片区顺路安排，减少往返。
- 住宿建议：地铁2号线或4号线沿线，或前门、南锣鼓巷附近，便于夜间返回。
- 每日预留 30–60 分钟弹性时间，应对排队与交通延误。

## Day 1：中轴线经典线

- 08:30–09:30 天安门广场（按预约时段入场，需提前预约）。
- 09:30–13:00 故宫博物院（中轴线+珍宝馆，约3–4小时，需提前7天预约，周一闭馆）。
- 13:00–14:00 午餐：前门大栅栏一带。
- 14:30–16:00 景山公园登万春亭俯瞰故宫全景。
- 17:00–19:00 前门大栅栏晚餐，品尝北京小吃。
- 交通：地铁1号线天安门东/西站，景点间以步行为主。
- 备选方案：故宫预约失败时改去中国国家博物馆（需预约）或北海公园；景山闭园时改去什刹海。

## Day 2：长城一日

- 07:30–09:00 前往八达岭长城（市郊铁路S2线或旅游专线）或慕田峪长城（专线巴士）。
- 09:00–13:00 长城游览，建议乘缆车/索道节省体力。
- 13:00–14:00 午餐：长城景区附近。
- 15:30–17:00 返程后顺路游览奥林匹克公园（鸟巢、水立方外观）。
- 18:00–19:30 晚餐：奥林匹克公园附近或返回市区。
- 交通：八达岭可乘市郊铁路S2线或旅游专线；慕田峪可乘专线巴士。
- 备选方案：体力有限时改乘缆车/索道；天气不佳时改去中国国家博物馆或首都博物馆（需预约）。

## Day 3：皇家园林线

- 08:30–11:30 颐和园（东宫门进，昆明湖、长廊、佛香阁）。
- 11:30–12:30 午餐：颐和园附近。
- 13:00–16:00 圆明园遗址公园（与颐和园相邻，顺路游览）。
- 17:00–19:00 中关村或五道口晚餐。
- 交通：地铁4号线北宫门站/圆明园站。
- 备选方案：颐和园限流时改去北海公园或恭王府（需预约）；圆明园闭园时改去清华大学艺术博物馆（需预约）。

## Day 4：天坛与什刹海

- 08:30–11:00 天坛公园（祈年殿、回音壁）。
- 11:00–12:00 午餐：天坛附近。
- 13:00–16:00 什刹海、南锣鼓巷一带逛老胡同，可参观恭王府（需预约）。
- 16:00–17:30 根据返程时间安排送站。
- 交通：地铁5号线天坛东门站，8号线什刹海站。
- 备选方案：恭王府预约失败时改去雍和宫（需预约）或国子监；返程时间紧张时只逛什刹海。

## 预算参考

- 淡季（11月–次年3月）：人均约2000–3000元。
- 旺季（4月–10月及法定节假日）：人均约3000–4500元。
- 门票参考：故宫旺季60元/淡季40元，颐和园旺季30元/淡季20元，天坛联票旺季34元/淡季28元，八达岭长城旺季40元/淡季35元。

## 风险提示

- 闭馆风险：故宫、国家博物馆等周一闭馆，行程需避开。
- 限流风险：热门场馆旺季限流，预约失败时启用备选景点。
- 天气风险：冬季寒冷、夏季高温多雨，长城与户外行程需关注天气预报。
- 预约规则与开放时间可能调整，出行前务必查询官方最新公告。
